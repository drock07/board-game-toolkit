Dice, shuffles and random draws all come from one place: the seeded random
number generator in the game's state. A game rolls the same numbers every
time it's replayed from the same seed and inputs, so saves, replays and tests
keep working however much luck is involved.

## Roll with tx.random

Rules code rolls through `tx.random`, in a step, an action's `execute`, or an
effect's `resolve`. Here's [Roll Five](/board-game-toolkit/examples/roll-five/)
rolling every die the player isn't holding:

<Source file="games/roll-five/game.ts" region="roll" />

`tx.random.roll(D6)` returns one of the die's faces. `tx.random` also has
`int(n)`, `float()`, `pick(array)` and `shuffle(array)`; see
[Determinism](/board-game-toolkit/concepts/determinism/) for the table.
`tx.shuffle(zone)` shuffles a zone with the same generator.

Never use `Math.random()` in rules code. It isn't part of the state, so a
replay rolls different numbers, and a save loads into a game that has
already diverged.

## Dice are their faces

A die is `{ faces: [...] }`, and a roll picks one face uniformly. The engine
ships `D4`, `D6`, `D8`, `D10`, `D12`, `D20` and `D100`, whose faces are the
numbers from 1, and `Fudge`, whose faces are two each of `-1`, `0` and `+1`.

Your own dice are the same shape:

<Source file="snippets/dice.ts" region="dice" />

- **The faces type the roll.** `roll` returns the die's face type: a
  `number` for `D6`, `-1 | 0 | 1` for `Fudge`, and `"hit" | "miss" | "crit"
| "shield"` for `combatDie`, because its faces are `as const`.
- **Repeat a face to weight it.** Two of the combat die's six faces are
  `"hit"`, so a hit comes up a third of the time.
- **Faces can be any JSON**: strings, numbers, records. Annotate the die as
  `Die<Yield>` to name the face type yourself. Faces must be JSON because a
  roll's result usually ends up in the vars.

## Where the dice live

A die whose value matters only for now belongs in the vars. Roll Five keeps
this turn's five dice and which are held in `vars.dice` and `vars.held`, and
the turn counts its own rolls, so there's no roll counter to reset:

<Source file="games/roll-five/game.ts" region="turn" />

`limits: { roll: 3 }` allows three rolls a turn, and `first: ["roll"]` makes
rolling the only legal first answer. `toggleHold` reads the roll count in
its `validate` with `turnNode.shown(s)`, so you can't hold after the last
roll. See the
[turn reference](/board-game-toolkit/reference/flow/turn/).

Make dice **entities** instead when they move between places or can be
hidden: a pool you draft from, a tray per player, a die rolled behind a
screen. Put the face in the entity's props and roll with
`tx.update(die, { face: tx.random.roll(D6) })`. The zone's visibility then
decides who sees the result. See
[Boards and zones](/board-game-toolkit/guides/boards/).
