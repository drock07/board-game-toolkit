Card games run on what players can't see: the deck's order, each other's
hands, the dealer's hole card. The engine keeps those secrets for you. Each
zone says who may see its entities, and every
[view](/board-game-toolkit/concepts/views/) and event a player gets is
filtered by it. This guide walks through
[Crazy Eights](/board-game-toolkit/examples/crazy-eights/) and
[Blackjack](/board-game-toolkit/examples/blackjack/), and then the rules your
own code has to follow so it doesn't leak what the engine hides.

## Declare who sees what

Crazy Eights has a deck no one sees, a discard pile whose top card everyone
sees, and a hand per player that only its owner sees:

<Source file="games/crazy-eights/game.ts" region="box" />

| Visibility           | Who sees the entities                              |
| -------------------- | -------------------------------------------------- |
| `"public"` (default) | Everyone.                                          |
| `"hidden"`           | No one.                                            |
| `"owner"`            | The player who owns the instance: `hand.of("p2")`. |
| `"top"`              | Everyone sees the top entity; the rest are hidden. |

`"owner"` needs `perPlayer: true`, since an instance needs an owner; the
types reject it on a shared zone. Anyone who owns no zone, like
`"spectator"`, sees only what's public.

## What a player sees

A card the viewer can't see is a **placeholder**: `{ ref, zone, hidden:
true }`. It says where a card is, and nothing that tells it apart:

<Source
  file="snippets/hidden-information.test.ts"
  region="views"
  title={false}
/>

- **Placeholders keep counts public.** Everyone sees how many cards each hand
  and the deck hold, as at a real table.
- **Views key entities by ref, not id.** A ref (`r12`) is a public handle. An
  id would give a card away (`card#1` was created first), so a placeholder
  never carries one.
- **A shuffle renews refs.** Every entity in a shuffled zone gets a new ref,
  so a player can follow a face-down card they watched move, but not through
  a shuffle.

To render a zone, read it with `viewEntities(view, zone)`, draw a card back
for a placeholder (`"hidden" in e`), and a face otherwise; `card.is(e)`
narrows to a card with typed props. Key each element by `ref`, which every
entry has.

## Face down in a public zone

Sometimes one card in a public zone is hidden, like Blackjack's hole card.
The dealer's hand is public; the second card is dealt with `faceUp: false`:

<Source file="games/blackjack/game.ts" region="deal" />

`faceUp` on an entity overrides its zone: `false` hides it from everyone,
`true` shows it to everyone. `tx.flip(id, true)` turns it up when the dealer
plays:

<Source file="games/blackjack/game.ts" region="reveal" />

Moving an entity clears its `faceUp` unless the move sets one. In a `"top"`
zone the engine sets `faceUp` itself, turning the top card up and the rest
down, so you never flip a discard pile by hand.

## Three ways to give a card away

The engine filters views and events. Your code can still leak a secret
through what isn't filtered.

### Hidden ids in vars

Vars are public: every player's view has them in full. If you store the id of
a card in a hidden zone in the vars, a player can follow that card. Store
what the rules need once it's public (Crazy Eights stores the active color,
not the card that set it), and keep references to hidden cards in zones.

### Who is asked

`actors()` and `view.waiting` are public. They tell every player who the game
is waiting on, so who's asked must never depend on a hidden card.

An [ability](/board-game-toolkit/concepts/effects/) carried by a card runs
only while that card is in its zone, and asks the card's owner. Carried by a
card in a hand, it gives the card away the moment it asks:

<Source file="snippets/hidden-information.ts" region="carried" />

When p1 strikes p2, the game waits on p2 only if p2 holds a Counter, and p1
can see that. Write the reaction as a game-wide ability that always asks the
target, and check the hand in the action's `validate` instead:

<Source file="snippets/hidden-information.ts" region="asks" />

Now every strike asks its target, holding a Counter or not. Only the target's
legal inputs, which nobody else sees, show whether they can counter.

### Whispers

An [effect](/board-game-toolkit/concepts/effects/) is in every player's
events unless it has `to`. For an effect that names a hidden card, like
"you drew the Bomb", give it `to: (d) => [d.player]` so only that player
gets it.

## Fuzzing checks the engine's part

`fuzz` fails if any view or event carries a hidden entity's id or props, or
an effect whispered to someone else, and checks every player's view after
every input. It can't tell that your vars or your abilities give a card
away; that's the part this guide is for. See
[Testing](/board-game-toolkit/guides/testing/#fuzzing).
