Every example's flow, drawn with `FlowGraph` from
`@drock07/board-game-toolkit-react/devtools`. Sequences run left to right,
branch cases and outcome handlers stack, and nodes that repeat (`loop` and
`turns`) are marked ↻. Effects and abilities follow the flow. On a game page,
the **Devtools** button shows the same graph live: running nodes are outlined
and nodes waiting for input are filled. See
[Devtools](/board-game-toolkit/guides/devtools/) and
[Flow](/board-game-toolkit/concepts/flow/).
