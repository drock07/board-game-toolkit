and the highest bid wins the lot.

## How it works

**A bid is an entity in its bidder's own zone.** `sealed` is a per-player
zone with `"owner"` visibility, so only the bidder sees their bid. Everyone
else's view holds a placeholder: they can see that you've bid, not how much.
Switch **Viewing as** to check.

<Source file="games/sealed-bids/game.ts" region="box" />

Bids aren't vars, because vars are public. The rule: if it hides, it's an
entity in a zone. See [Hidden information](/board-game-toolkit/guides/hidden-information/).

**Everyone bids at once.** Each lot is a round of three nodes:

<Source file="games/sealed-bids/game.ts" region="round" />

- **The first step** destroys last round's bids, unseen, and takes the next
  lot.
- **`everyone`** gives each player their own prompt, on their own fiber.
  They answer in any order, once each, and the node ends when all are in. See
  [Simultaneous turns](/board-game-toolkit/guides/simultaneous-turns/).
- **The last step** reads every bid, pays the winner's, and causes `sold`.

**The action reads its actor.** Several players answer the same action, so
`placeBid` uses `actor`, the player who sent the input, for their coins and
their zone:

<Source file="games/sealed-bids/game.ts" region="placeBid" />

**A sale is an effect the page waits on.** `sold` is an effect with no
`resolve`: just a typed event. The page gives each result a moment on screen
with `useGameEffect`, and the bots get a delay so you can watch them:

<Source file="games/sealed-bids/SealedBids.tsx" region="host" />
