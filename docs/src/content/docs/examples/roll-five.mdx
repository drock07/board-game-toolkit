Roll five dice up to three times a turn, holding the ones you like, then score
them in one of thirteen categories.

<Example slug="roll-five" />

## How it works

**The dice are vars.** Five dice and which are held don't move between places
or hide, so they're data, cleared when you score. Nothing in vars counts your
rolls; the turn does that.

<Source file="games/roll-five/game.ts" region="types" />

**Each round is one `turn` node.** It holds a single prompt open across
several answers:

<Source file="games/roll-five/game.ts" region="turn" />

- **`limits: { roll: MAX_ROLLS }`**: `roll` stops being offered after three.
- **`first: ["roll"]`**: rolling is the only way to start a turn.
- **`score`** returns `"end"`, which closes the turn. `roll` and `toggleHold`
  return nothing, so the turn waits for the next answer.

The rounds are `turns({ rounds: CATEGORIES.length }, …)`, thirteen passes for
one player, inside a session loop that clears the sheet and waits on "Play
again". See [`turn`](/board-game-toolkit/reference/flow/turn/).

**The dice come from the seeded RNG.** `tx.random.roll(D6)` draws from the
generator stored in the state, so the same seed and inputs roll the same
numbers. Held dice keep their faces. See
[Dice](/board-game-toolkit/guides/dice/).

<Source file="games/roll-five/game.ts" region="roll" />

**Rules read the turn's counts too.** The turn keeps how many times each
action was taken in its own frame and publishes them as what it shows.
`toggleHold` reads them with `turnNode.shown(s)`: after the last roll,
holding a die would change nothing, so it isn't legal.

<Source file="games/roll-five/game.ts" region="hold" />

**The UI reads the same counts.** `turnNode.shown(g.view)` gives the page the
roll count for "Roll 2/3". It's `undefined` between games, when no turn is
running. See [What nodes show](/board-game-toolkit/reference/flow/shown/).
