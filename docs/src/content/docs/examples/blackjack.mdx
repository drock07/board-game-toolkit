Bet, play your hand, and watch the dealer play theirs. Run out of chips and
the bankroll resets.

<Example slug="blackjack" />

## How it works

**Guards end the hand early.** The `play` seq declares
`exits: { natural, bust }`. Guards are checked after every transaction, so
hitting to 22 ends `play` at once and the dealer never takes a turn. See
[Outcomes and guards](/board-game-toolkit/concepts/outcomes/).

**The decision stays open until you stand.** `hit` sets `ends: false`, so the
decision prompts again after it. Its `endWhen: "playerAt21"` closes it on 21
without asking.

**A branch handles going broke.** It uses an inline
[expression](/board-game-toolkit/reference/spec/expressions/), not a named condition:
`{ lte: [{ var: "vars.bankroll" }, 0] }`.

<Source file="games/blackjack/spec.ts" />

**The hole card is face down in a public zone.** The dealer's zone is public,
but the second card is dealt with `faceUp: false`, which overrides the zone for
that one entity:

the card from then on:
