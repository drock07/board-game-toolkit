A **view** is the state as one player may see it. UIs render views, bots
decide from them, and a server sends each client only theirs. Nothing in a
view tells a player what they couldn't know at a real table.

## What a view holds

| Field               | What it is                                                        |
| ------------------- | ----------------------------------------------------------------- |
| `player`, `players` | Whose view it is, and every seat in order.                        |
| `vars`              | The game's vars, in full: vars are public.                        |
| `zones`             | Each zone's entities, as refs, top first.                         |
| `entities`          | Each entity by ref: the entity, or a placeholder.                 |
| `status`, `result`  | Whether the game is running, and its result once it ends.         |
| `waiting`           | What the flow waits on: each open prompt's `label` and `actors`.  |
| `shown`             | What nodes publish, read with `turnNode.shown(view)` and friends. |

`viewEntities(view, zone)` reads a zone's entities in order, typed by the
zone.

## Hidden entities

An entity the viewer can't see is a **placeholder**: `{ ref, zone, hidden:
true }`. It says where a card is, and nothing that tells it apart: not its id,
not its props.

Views key entities by **ref** (`r12`), a public handle, not by id. A shuffle
gives every entity in the zone a new ref, so a player can follow a face-down
card they watched move, as at a real table, but not through a shuffle. And a
placeholder never carries the id, which would often give the card away
(`card#1` was created first).

## Who sees what

An entity is visible to a viewer when:

1. it has a `faceUp` override: `true` shows it to everyone, `false` hides it
   from everyone; or else
2. its zone's visibility allows it:

| Visibility           | Who sees the entities                                |
| -------------------- | ---------------------------------------------------- |
| `"public"` (default) | Everyone.                                            |
| `"hidden"`           | No one.                                              |
| `"owner"`            | The player who owns the zone instance, `hand.of(p)`. |
| `"top"`              | Everyone sees the top entity; the rest are hidden.   |

`faceUp` is how a card is face down in a public zone, like Blackjack's hole
card: `tx.moveTop(shoe, dealer, 1, { faceUp: false })`, then `tx.flip(id,
true)` to reveal it. Moving an entity clears its override unless the move
sets one. In a `"top"` zone the engine manages `faceUp` itself, turning the
top card up and the rest down as they change.

A spectator is any viewer who owns no zone: `view(game, state, "spectator")`
sees only what's public.

## Rules that keep secrets secret

- **Vars are public.** Keep anything secret in an owner or hidden zone. Don't
  store the ids of hidden entities in vars; a player could follow the card.
  See [State](/board-game-toolkit/concepts/state/).
- **`who` is public.** `actors()` and `view.waiting` say who the flow is
  waiting on, so the choice of who must not depend on hidden cards. An
  ability carried by a card in a hidden hand reveals that card by asking its
  owner. Write it as a game-wide ability that always asks; see
  [Effects and abilities](/board-game-toolkit/concepts/effects/).
- **Effects can be whispered.** An effect with `to` is only in those players'
  events.

`fuzz` checks the first rule for you: it fails if any view shows an entity
its player can't see, or carries a hidden entity's id or props.

## Views and events agree

Every [event](/board-game-toolkit/concepts/events/) carries what it changed,
and `viewEvents` filters them per player with the same rules. Replaying a
player's events onto their old view gives exactly their new view, and `fuzz`
checks that on every input.
