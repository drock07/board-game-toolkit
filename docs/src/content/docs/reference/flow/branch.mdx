```ts
branch(id, [{ when, then }, ...], otherwise?, opts?)
// { kind: "branch", id, cases: [{ when, then }], else? }
```

Checks each case's `when` in order and runs the first one that holds. If none
do, it runs `else`, or ends at once if there's no `else`. The `branch` ends
when the chosen flow does.

| Option  | Type                               | Meaning                                                  |
| ------- | ---------------------------------- | -------------------------------------------------------- |
| `cases` | `{ when: Cond; then: FlowNode }[]` | Checked in order; the first match runs.                  |
| `else`  | `FlowNode`                         | Runs when no case matches. The builder's third argument. |

`when` can be a named condition or an inline
[expression](../../spec/expressions/), as the demo shows.
