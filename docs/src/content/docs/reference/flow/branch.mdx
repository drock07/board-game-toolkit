`branch` chooses what happens next from the state: a different prompt when
you find treasure, a dealer's turn only if someone's still in. You write
`branch(cases, otherwise?)`.

| Argument    | Type                               | What it is                                           |
| ----------- | ---------------------------------- | ---------------------------------------------------- |
| `cases`     | `{ when: (s) => boolean; then }[]` | Checked in order; the first whose `when` holds runs. |
| `otherwise` | `Node`                             | Runs when no case holds. Optional.                   |

## Demo

A step rolls a die; a roll of 5 or 6 finds treasure, anything else finds
nothing. Each leads to its own prompt.

## Behavior

- **Decided once.** The cases are checked when the `branch` starts. The
  chosen node runs to its end even if the state changes so that another
  case would hold.
- **Nothing to do is fine.** With no case holding and no `otherwise`, the
  `branch` ends at once.
- **Ends with its choice.** The `branch` ends when the chosen node does.

For a check that should hold the whole time, not just at the start, use a
guard on [`outcomes`](/board-game-toolkit/reference/flow/outcomes/) instead.
