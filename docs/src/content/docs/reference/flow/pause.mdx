```ts
pause(id, { actor?, label?, ...common })
// { kind: "pause", id, actor?, label? }
```

Opens a prompt that only asks to continue: end of a round, a reveal, "Play
again". An input answers with `{ continue: true }`.

| Option  | Type     | Meaning                                                            |
| ------- | -------- | ------------------------------------------------------------------ |
| `actor` | `Actor`  | Who may continue. Defaults to `"any"`: the first player to answer. |
| `label` | `string` | Text for the button, carried on the prompt.                        |
