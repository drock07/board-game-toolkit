A `step` is the automatic part of a game: shuffling and dealing, scoring a
round, refilling a market, the dealer playing out their hand. You write
`step(run)`.

| Argument | Type                       | What it is                                                        |
| -------- | -------------------------- | ----------------------------------------------------------------- |
| `run`    | `(tx) => void \| { exit }` | Rules code. It may return `{ exit: "name" }` to raise an outcome. |

## Behavior

- **One transaction.** `run` gets a `tx` and everything it changes is one
  transaction: its events are logged together, and abilities and caused
  effects run once it ends, before the flow moves on.
- **Never waits.** A step runs and ends. To ask a player something, follow
  it with a [`prompt`](/board-game-toolkit/reference/flow/prompt/).
- **Knows where it is.** `tx.actor` is the player the flow is bound to
  there: whose turn it is inside `turns`, the fiber's player inside
  `simultaneous`, the owner inside an ability. `tx.shown` reads what the
  nodes around it show, such as the turn number.
- **Ends things.** `tx.end(result)` ends the game. Returning
  `{ exit: "name" }` raises an outcome to the nearest
  [`outcomes`](/board-game-toolkit/reference/flow/outcomes/) that lists it.
