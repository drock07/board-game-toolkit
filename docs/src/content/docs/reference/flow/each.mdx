```ts
each(id, over, body, { mode?, until?, repeat?, ...common })
// { kind: "each", id, over, body, mode?, until?, repeat? }
```

Runs `body` once per item, binding the item in scope.

### `over`

| `over`                            | Iterates                                                      | Binds          |
| --------------------------------- | ------------------------------------------------------------- | -------------- |
| `{ players: "clockwise" }`        | Players in seat order.                                        | `scope.player` |
| `{ players: "counterclockwise" }` | Players in reverse seat order.                                | `scope.player` |
| `{ players: …, from: "first" }`   | Starting with the first seat. The default.                    |                |
| `{ players: …, from: "random" }`  | Starting from a seat drawn from the seeded RNG.               |                |
| `{ players: …, from: { ref } }`   | Starting from the first player an `impl.lists` entry returns. |                |
| `{ ref: "name" }`                 | The items an `impl.lists` entry returns.                      | `scope.item`   |

Inside an `each` over players, `actor: "current"` means the bound player.

### Options

| Option   | Type                                     | Meaning                                                                                                                       |
| -------- | ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `mode`   | `"sequential"` (default) or `"parallel"` | In parallel mode, every item's body runs at once, each on its own fiber, and the `each` ends when all have finished.          |
| `repeat` | `boolean`                                | After the last item, start another pass. The items are recomputed each pass, so eliminated players drop out. Sequential only. |
| `until`  | `Cond`                                   | Checked after each item. Ends the `each` when true. Sequential only.                                                          |

A repeating `each` over players with an `until` is the usual shape for "take
turns until someone wins". A parallel `each` is the shape for "everyone
chooses at once": see [Sealed Bids](../../../examples/sealed-bids/) and
[Simultaneous turns](../../../guides/simultaneous-turns/).
