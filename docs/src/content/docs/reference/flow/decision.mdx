```ts
decision(id, { actor, endWhen?, ...common }, actions)
// { kind: "decision", id, actor, actions: { name: { ends?, then? } }, endWhen? }
```

Opens a prompt offering its actions to its actors. When one answers, the
action runs; then the decision ends, or prompts again.

| Option               | Type                           | Meaning                                                                                                                       |
| -------------------- | ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `actor`              | `Actor`                        | Who may answer: `"current"`, `"any"`, a player id, or `{ ref }`. See [Prompts and inputs](../../../concepts/prompts/#actors). |
| `actions`            | `{ [name]: { ends?, then? } }` | The actions offered. Each name must be an `impl.actions` entry.                                                               |
| `actions[name].ends` | `boolean`                      | Whether the decision ends after this action. Defaults to `true`.                                                              |
| `actions[name].then` | `FlowNode`                     | A flow to run after the action executes, before the decision ends or prompts again.                                           |
| `endWhen`            | `Cond`                         | Checked whenever the decision would prompt again. Ends it when true.                                                          |

The prompt is `{ kind: "decision", actions: [{ name, ends }], … }`. An input
answers with `{ action, args? }`.

### The action itself

Each action is an `impl.actions` entry:

```ts
actions: {
  hit: {
    validate: (s, args, scope) => true, // or a reason string
    execute: (tx, args) => { ... },
    enumerate: (s, scope) => [/* every legal args value */],
  },
}
```

All three are optional except `execute`. See
[Prompts and inputs](../../../concepts/prompts/#validating-actions).

## Demo

Hit (`ends: false`) until you stand or reach 21 (`endWhen`). Double is only
allowed on 11 or less (`validate`), and runs a `then` flow.
