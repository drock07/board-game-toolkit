This page builds Tic-Tac-Toe: two players, a 3×3 board, turns that alternate
until someone makes a line. Every code sample here is from the
[Tic-Tac-Toe example](/board-game-toolkit/examples/tic-tac-toe/), which you
can play, and from tests that run in CI, so they're known to work.

You'll write two files:

```
tic-tac-toe/
  game.ts    the game: its state, actions and flow
  Board.tsx  a React UI
```

Install the packages first; see [Installation](/board-game-toolkit/start/installation/).

## 1. Decide what the state is

A game's own state is its **vars**: any JSON you like. Tic-Tac-Toe's board is
nine cells, plus who's winning and a running score.

<Source file="games/tic-tac-toe/game.ts" region="types" />

There are no zones here. Zones are for things that move between places and can
be hidden, like cards; the board is just data. (A card game would declare
entity types and zones first; see [The model](/board-game-toolkit/concepts/model/).)

Then bind the vars type with `define`. It returns the game's **core**: `rules`,
`action`, and the node builders the flow is made of.

<Source file="games/tic-tac-toe/game.ts" region="core" />

## 2. Write the actions

An action is something a player can do. It has up to three parts:

<Source file="games/tic-tac-toe/game.ts" region="actions" />

- **`enumerate`** lists the args a player could pass, here every empty cell.
  Bots, fuzzing and UIs use it to find the legal moves. An action with no
  args leaves it out, like `again`.
- **`validate`** says whether some args are legal now, with a reason when
  they're not. Without it, the enumerated args are the legal ones.
- **`execute`** changes the state, through a transaction `tx`: here, writing a
  mark into the vars. `actor` is the player taking the action.

The args are typed from what `enumerate` returns, so `index` is a `number`
everywhere, and the handle `placeMark` builds a typed input:
`placeMark.by("p1", { index: 4 })`.

## 3. Put it in order

`rules` takes the player count, a `setup` that creates the starting state, and
the **flow**: a tree of nodes that says what happens in what order.

<Source file="games/tic-tac-toe/game.ts" region="rules" />

Reading the flow from the outside in:

- **`loop({}, …)`**: play games forever. A flow must either loop or end the
  game with `tx.end()`, so it always has something to do.
- **`seq(…)`**: one game is these four children, in order.
- **`step(…)`**: run rules code in one transaction, without waiting for
  anyone. The first step clears the board and draws a random starter with
  `tx.random`, which is seeded, so games replay exactly.
- **`turns({ from, until }, …)`**: players take turns at the body in seat
  order, starting from `from`, until `until` holds.
- **`prompt({ label }, placeMark)`**: wait for the current player to take one
  of these actions. The label is what UIs show while it waits.
- **The last step** records the result; then a prompt waits for "Play again".

## 4. Play it in a test

A game is a plain value, so you can play it anywhere. `init` starts one from
its players and a seed, and `apply` (here `applyOrThrow`, a test helper) plays
an input:

<Source file="snippets/quickstart.test.ts" region="play" />

`actors` says who may act now, and `legalInputs` lists what they may do. The
view's `waiting` says what the flow is waiting on, with the prompt's label.

## 5. Fuzz it

`fuzz` plays many random games and checks every step: that each input it's
offered is legal, that no view shows what its player can't see, and that the
events replay to exactly the new state and every player's view.

<Source file="snippets/quickstart.test.ts" region="fuzz" />

## 6. Put it on screen

`useGame` runs the game for a React component: it gives you the viewer's
`view`, who may act, their `legal` inputs, and `submit`. A seat can be played
by a bot, here the engine's `randomBot`.

<Source file="snippets/Board.tsx" region="board" />

- **`g.view.vars`** is what you render. Views hide what the viewer can't see;
  Tic-Tac-Toe has nothing hidden.
- **`g.legal`** drives the buttons: a cell is clickable only if placing a mark
  there is a legal input. Submitting it plays it.
- **`g.actors`** says who the game is waiting on.

The [example's UI](/board-game-toolkit/examples/tic-tac-toe/) adds animation
and a minimax bot that never loses.
